# 🐍 Python Mini Projects

Python becerilerimi geliştirmek amacıyla hazırladığım 20 farklı mini projeden oluşan çalışma reposudur.

Bu projeler sayesinde Python'ın temel yapılarından başlayarak API kullanımı, dosya işlemleri, OOP, JSON, hata yönetimi ve harici kütüphane kullanımına kadar birçok konuda pratik yaptım.
